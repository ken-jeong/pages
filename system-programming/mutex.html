MUTEX

<pthread.h> · 재귀 뮤텍스
  • 기본 공유 범위는 같은 프로세스의 스레드
  • 소유 스레드가 pthread_mutex_unlock()으로 해제
  • PTHREAD_MUTEX_RECURSIVE를 지정해야 재진입 가능
  • PTHREAD_MUTEX_NORMAL은 같은 스레드의 재잠금 시 교착
  • 대기 순서는 설명을 위한 FIFO 표시이며 실제 획득 순서는 보장되지 않음
pthread_mutex_t mutex;
pthread_mutexattr_t attr;
pthread_mutexattr_init(&attr);
pthread_mutexattr_settype(&attr, PTHREAD_MUTEX_RECURSIVE);
pthread_mutex_init(&mutex, &attr);
pthread_mutexattr_destroy(&attr);

pthread_mutex_lock(&mutex);
/* 임계 영역: 재잠금한 횟수만큼 unlock 필요 */
pthread_mutex_unlock(&mutex);

/* 모든 스레드의 사용이 끝난 뒤 */
pthread_mutex_destroy(&mutex);

호출 흐름을 보여주는 예제입니다. 실제 C 코드에서는 반환값을 검사하세요.
