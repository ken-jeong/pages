SEMAPHORE

<semaphore.h> · POSIX 세마포어
  • sem_wait(): 카운트가 양수면 1 감소, 0이면 대기
  • sem_post(): 소유권 검사 없이 토큰 1개 추가, 대기 스레드를 깨움
  • pshared=0: 같은 프로세스의 pthread 스레드 간 공유
  • 초기값 3은 상한이 아님. 실제 sem_post()는 SEM_VALUE_MAX까지 증가 가능
  • 이 시각화는 사용한 자원만 반환하며, 대기 순서는 설명을 위해 FIFO로 표시
  • 초기값 1에서 반환 규칙으로 0/1을 유지하면 binary semaphore로 사용 가능
sem_t sem;
sem_init(&sem, 0, 3);

/* pthread 스레드에서 */
while (sem_wait(&sem) == -1) {
    if (errno != EINTR) {
        /* 오류 처리: 자원을 사용하지 않고 종료 */
        return NULL;
    }
}
/* 자원 사용 */
sem_post(&sem);

/* 모든 스레드의 사용이 끝난 뒤 */
sem_destroy(&sem);

pthread.h와 별도로 semaphore.h와 errno.h를 포함합니다. sem_wait()의 신호 중단(EINTR)은 재시도하며, 실제 C 코드에서는 나머지 호출의 반환값도 검사하세요.
