pthread_rwlock
읽기 공유 · 쓰기 독점 · 대기 큐

읽기 잠금은 여러 스레드가 공유합니다. 쓰기 잠금은 모든 읽기·쓰기 스레드와 배타적입니다.
읽는 중 / shared readers
쓰는 중 / exclusive writer
획득 대기 / R = 읽기 · W = 쓰기

READ-WRITE LOCK

<pthread.h> · pthread_rwlock_t
  • 체험 순서: rdlock 두 번 → wrlock → rdlock → 읽기 unlock 두 번 → 쓰기 unlock
  • rdlock: 쓰기 소유자가 없고 대기 정책상 허용되면 읽기 잠금을 함께 획득합니다.
  • wrlock: 읽기 소유자와 쓰기 소유자가 모두 없어야 획득합니다.
  • unlock: 잠금을 보유한 스레드가 자신의 잠금을 해제합니다. 이 예제는 가장 먼저 진입한 읽기 스레드부터 해제합니다.
  • 설명용 FIFO 정책: 대기 쓰기 스레드 뒤의 신규 읽기는 추월하지 않습니다. 연속된 대기 읽기는 함께 진입합니다.
  • POSIX가 이 FIFO 정책을 보장하지는 않습니다. 실제 읽기·쓰기 우선순위와 기아 가능성은 구현·스케줄링 정책에 따라 달라집니다.
pthread_rwlock_t lock = PTHREAD_RWLOCK_INITIALIZER;

/* 읽기 스레드: 공유 데이터를 변경하지 않음 */
pthread_rwlock_rdlock(&lock);
/* 공유 데이터 읽기 */
pthread_rwlock_unlock(&lock);

/* 쓰기 스레드 */
pthread_rwlock_wrlock(&lock);
/* 공유 데이터 변경 */
pthread_rwlock_unlock(&lock);

/* 모든 스레드의 사용이 끝난 뒤 */
pthread_rwlock_destroy(&lock);

각 잠금 요청은 새 스레드입니다. 재귀 잠금·읽기에서 쓰기로의 승격은 다루지 않습니다. 실제 C 코드에서는 반환값을 검사하세요.
