CRITICAL_SECTION

유저 모드 객체
  • 같은 프로세스 내 스레드 전용
  • 경쟁 없으면 커널 진입 X → 가장 빠름
  • 소유 스레드는 재진입 가능 (recursive)
  • WaitForSingleObject 사용 불가

MUTEX

커널 객체
  • 이름 부여 시 프로세스 간 공유 가능
  • 소유권 존재 → 소유 스레드만 해제, 재진입 가능
  • 소유 스레드 종료 시 abandoned 상태
  • 커널 전환 비용으로 상대적으로 느림

SEMAPHORE

커널 객체
  • 0~최대값 카운트로 N개 동시 접근 허용
  • 소유권 없음 → 어느 스레드든 Release
  • 자원 풀 제한에 적합
  • 최대값 1이면 binary semaphore

EVENT

커널 객체
  • 상호 배제가 아닌 스레드 간 신호 전달
  • Manual-Reset: 모든 대기 스레드를 깨움
  • Auto-Reset: 한 스레드만 깨우고 자동 리셋
  • SetEvent / ResetEvent로 제어, PulseEvent는 사용 지양
