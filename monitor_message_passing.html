MONITOR

  • 공유 자원 + 락 + 조건변수를 하나로 캡슐화
  • 한 번에 스레드 1개만 실행
  • wait() → 락 해제 후 조건 대기열에서 수면
  • signal() → 대기 중인 스레드를 깨움
  • Java synchronized, Python Condition

MESSAGE PASSING

  • 공유 메모리 없음 — 채널로만 통신
  • 버퍼 가득 → send() 블로킹
  • 버퍼 비면 → receive() 블로킹
  • Go channel, Erlang, Rust mpsc
  • 동기화 문제를 구조적으로 제거
