동시성 제어 / 유한 버퍼

생산자 / 소비자 시뮬레이터
Semaphore e · s · n

유한 버퍼 버전을 직접 돌려보세요. 생산자 실행 · 소비자 실행 버튼을 누르면 한 단계씩 진행되며, 세마포어 e · s · n 값과 버퍼 상태가 실시간으로 바뀝니다. 자동 재생으로 두 스레드가 경쟁·대기하는 흐름도 볼 수 있어요.

한 단계 실행 속도

생산자 (producer)

  • › produce();
  • › semWait(e); // 빈칸 확보
  • › semWait(s); // 잠금
  • › append();
  • › semSignal(s); // 해제
  • › semSignal(n); // 아이템+1

대기 중 — 버튼을 눌러 시작하세요

소비자 (consumer)

  • › semWait(n); // 아이템 대기
  • › semWait(s); // 잠금
  • › take();
  • › semSignal(s); // 해제
  • › semSignal(e); // 빈칸+1
  • › consume();
execution log

    핵심 규칙: semWait는 값을 1 줄이고, 0 이하가 되면 그 스레드는 블록(대기)됩니다. semSignal은 값을 1 늘려 대기 중인 스레드를 깨웁니다. 빈 버퍼에서 소비자가 semWait(n)에 막히거나, 꽉 찬 버퍼에서 생산자가 semWait(e)에 막히는 장면을 만들어 보세요. s는 한 번에 한 스레드만 버퍼를 건드리도록 보장합니다.
